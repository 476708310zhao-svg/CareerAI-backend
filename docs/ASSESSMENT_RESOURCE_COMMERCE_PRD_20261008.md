# 校招测评资料购买与资料库 PRD

> 文档版本：V0.1
> 更新日期：2026-10-08
> 产品范围：微信小程序、Node.js/Express 后端、运营管理后台
> 当前状态：产品规划，待评审
> 名词说明：本文“测评资料”指校招 OA、笔试、SJT、编程测评、Case Study 等备考内容，不指现有“求职机构测评”。

> 交付边界（2026-10-10）：本 PRD 未纳入功能简化 Checkpoint 1–9 的运行代码交付。“已购资料”当前仅保留分类/入口和诚实空态，没有独立功能开关；本文定义的商品、订单、支付、Grant、退款和私有内容接口均为后续规划，不能作为已上线能力宣传或验收。

## 1. 项目背景

当前运行代码已经具备内容资产中心、面试题库、OA 训练计划、计时练习、错题本，也有通用会员/订单/商业账本基础；但没有与测评资料绑定的商品、订单、Grant 或退款闭环。本 PRD 以下的“将”、“支持”和验收项均表示未来商业化候选意图，不是当前产品事实。

本项目拟增加独立的“校招测评资料库”，让用户能够按公司、岗位、招聘季和测评题型发现资料，购买后在小程序内持续阅读与练习，并将学习结果接入现有 OA Copilot。

本项目不是普通文件下载商城，也不以销售未经授权的所谓“原题”为目标。资料必须可解释来源、可追踪版本，并明确非官方性质和适用边界。

## 2. 产品目标

### 2.1 用户目标

1. 快速找到与目标公司、岗位和招聘季匹配的测评资料。
2. 购买前能够通过目录、样章、更新时间和适用范围判断资料是否值得购买。
3. 购买后立即获得稳定、跨设备的资料访问权。
4. 在一个产品内完成阅读、练习、收藏、笔记和错题复盘。
5. 将资料学习直接转化为 OA 训练计划，而不是在多个工具之间手工搬运。

### 2.2 业务目标

1. 建立除 Pro 会员外的单品和专题包收入模式。
2. 沉淀可持续更新的校招测评内容资产。
3. 验证“免费样章—购买—学习—训练”的转化链路。
4. 建立商品、订单、授权、退款和内容版本的可审计机制。

### 2.3 首版成功标准

- 首批至少发布 10 个审核通过的商品，其中至少包含 3 个免费样章商品、4 个公司专项包和 3 个题型专项包。
- Mock 环境完整跑通浏览、下单、支付确认、授权、阅读、退款申请和授权撤销。
- 支付成功后资料权限正常到账，重复支付回调不重复授权。
- 已购买用户可以跨设备查看资料和学习进度。
- 资料练习可以创建或关联 OA 训练计划，错题可进入现有错题本。
- 未授权用户不能通过猜测 URL、分享 URL 或缓存接口读取付费内容。

## 3. 用户与使用场景

### 3.1 目标用户

| 用户类型 | 核心诉求 |
|---|---|
| 有明确目标公司的应届生 | 获取该公司当季测评流程、题型说明和专项练习 |
| 同时准备多家公司的用户 | 购买行业或招聘季组合包，减少重复搜索 |
| 某类题型薄弱的用户 | 购买数理、逻辑、SJT、编程等专项训练资料 |
| 已进入 OA 阶段的用户 | 在截止日期前制定训练计划并集中练习 |
| 运营人员 | 上架、更新、审核资料，处理订单、授权和退款 |

### 3.2 核心场景

1. 用户在求职进度中把某申请更新为“OA”，系统推荐对应公司或题型资料。
2. 用户从资源中心进入测评资料库，按公司或题型筛选资料。
3. 用户阅读免费样章，确认目录、版本和更新时间后购买。
4. 支付完成后进入“我的资料”，继续阅读或开始练习。
5. 用户将资料中的题型加入 OA 计划，练习结果和错题进入现有 OA 数据体系。
6. 运营更新资料的小版本，已购买该版本的用户收到更新提示并继续访问。

## 4. 产品原则

1. **资料商品与会员分离**：资料是特定内容访问权，会员和场景包是功能或额度权益，两者可以组合但不能混为一种权限。
2. **先预览再购买**：商品必须提供目录、适用范围、更新时间和样章，禁止只展示营销文案。
3. **支付与授权分离**：前端支付成功不等于资料解锁，必须由服务端确认订单后发放授权。
4. **内容版本可追踪**：已购买内容不能被运营无痕覆盖，更新必须留下版本和变更记录。
5. **不承诺命中原题**：展示训练价值和适用范围，不宣传“保过”“押题必中”或未经验证的官方关系。
6. **不新建第二套 OA 系统**：练习、计时、错题和能力统计复用现有 OA Copilot。
7. **私有交付**：付费文件不得放在公开静态地址中，所有内容访问必须校验用户授权。

## 5. 商品体系

### 5.1 商品类型

| 类型 | 示例 | 内容构成 |
|---|---|---|
| 公司专项包 | 2027 字节跳动校招测评准备包 | 流程说明、题型分布、专项练习、答题策略 |
| 题型专项包 | SHL 数理推理专项训练 | 方法讲解、分级练习、答案解析、错题建议 |
| 行业组合包 | 互联网秋招测评冲刺包 | 多家公司流程、通用题型和练习合集 |
| 岗位专项包 | 产品经理 Case Study 测评包 | 岗位相关案例、结构化分析和作答模板 |
| 免费体验包 | 数理推理入门 10 题 | 完整体验阅读和练习流程，用于转化 |

### 5.2 商品基础字段

- 商品 SKU、名称、短标题、封面、摘要
- 商品类型、公司、行业、岗位、地区、招聘季
- 测评类型、难度、标签
- 目录、章节数、题目数、解析数、预计学习时长
- 原价、销售价、销售状态
- 当前大版本、最后更新时间、更新日志
- 适用人群、不适用人群、使用说明
- 内容来源说明、原创/授权状态、审核记录
- 免费样章范围
- 访问有效期与更新政策
- 退款说明、客服入口

### 5.3 版本与访问政策

首版推荐采用以下规则：

- 每个招聘季或重大内容升级为一个大版本，例如 `2027.1`。
- 用户购买后永久访问所购大版本。
- 所购大版本内的小修订和勘误免费更新。
- 新招聘季作为新商品版本，不自动覆盖旧版本。
- 下架商品不再售卖，但不影响合法已购用户访问；版权或安全原因强制撤下时，由运营给出替代方案并留下审计记录。

## 7. 用户端详细需求

### 7.1 资料首页

#### 页面目标

帮助用户在 30 秒内找到与目标公司、岗位或薄弱题型相关的资料。

#### 功能需求

- 顶部搜索：支持商品名、公司、岗位和题型关键词。
- 快捷分类：公司专项、题型专项、行业合集、免费体验。
- 筛选条件：招聘季、地区、岗位、题型、难度、价格、更新时间。
- 排序：综合推荐、最新更新、销量、价格。
- 运营位：近期热门公司、即将开始的校招、最新资料。
- 商品卡片显示：封面、名称、标签、更新时间、内容数量、价格、购买状态。
- 已购买商品卡片直接显示“继续学习”。
- 无结果时允许清空筛选，并推荐通用题型资料。

### 7.2 商品详情页

#### 页面区块

1. 商品基本信息：名称、价格、适用对象、版本和更新时间。
2. 内容亮点：包含哪些题型、章节、练习和解析。
3. 适用范围：公司、岗位、地区、招聘季。
4. 目录：明确区分免费、付费和暂未发布章节。
5. 免费样章：无需登录即可阅读公开内容；练习结果保存需要登录。
6. 版本记录：展示最近更新内容。
7. 来源与说明：原创/授权状态、非官方声明、风险提示。
8. 底部操作：立即购买、继续学习或查看订单。

#### 状态规则

- 未购买：只可访问公开介绍和样章。
- 已购买：显示“继续学习”和最近学习位置。
- 支付处理中：显示“订单确认中”，允许刷新订单状态。
- 已退款/授权撤销：保留订单记录，不允许访问付费章节。
- 已下架但已购买：仍允许访问，页面显示“已停止销售”。

### 7.3 购买确认与支付

#### 购买前确认信息

- 商品名称、版本、价格
- 访问期限和更新范围
- 已阅读的样章
- 退款与客服说明
- 用户协议和付费内容说明

#### 支付流程

1. 检查登录状态。
2. 服务端读取当前商品和价格，不接受前端传入成交金额。
3. 创建包含商品与版本快照的订单。
4. 拉起微信支付或开发环境 Mock 支付。
5. 服务端处理回调并校验订单、金额和幂等键。
6. 写入支付账本并发放资料访问 Grant。
7. 前端轮询订单状态，确认授权后进入购买成功页。

#### 异常处理

- 用户取消支付：订单保留为待支付，不授权。
- 支付完成但回调延迟：显示“权益同步中”，后台继续查询。
- 重复回调：返回成功，但不重复记账、不重复授权。
- 金额不符或签名失败：拒绝授权并触发告警。
- 商品下架或价格变化：旧确认页不可继续支付，需要重新确认。

### 7.4 购买成功页

- 商品名称和订单号
- 权益到账状态
- “立即学习”主按钮
- “查看我的资料”次按钮
- 资料更新和服务通知订阅入口
- 授权仍在同步时自动轮询并提供客服入口

### 7.5 我的资料

#### 列表分类

- 全部
- 学习中
- 已完成
- 已失效/已撤销

#### 卡片信息

- 商品名称、版本、封面
- 最近学习章节和学习进度
- 最后更新时间和是否有新内容
- 授权状态
- 继续学习、查看订单

#### 规则

- 以服务端授权为唯一可信状态。
- 跨设备同步最近阅读位置、收藏、笔记和完成状态。
- 已购多个版本时分别展示，不静默合并。
- 退出登录后清理本机付费内容缓存。

### 7.6 资料阅读器

#### 支持内容

- 富文本图文章节
- 受保护 PDF 预览
- 单选、多选、判断和简答练习
- 答案与解析
- 章节收藏和个人笔记
- 学习进度和最近阅读位置

#### 权限规则

- 每次打开付费章节时由服务端校验 Grant。
- PDF 和图片使用短期签名地址或鉴权代理，不返回永久公开地址。
- 本地只缓存必要展示数据；账号退出、授权撤销或缓存过期后不可继续打开。
- 首版不提供批量 ZIP、原始文件永久下载或跨账号分享。

### 7.7 OA Copilot 联动

- 商品详情可显示对应题型和建议训练计划。
- 已购买用户可以“一键创建 OA 计划”。
- 创建计划时预填公司、岗位、目标日期和题型。
- 资料练习产生的错题记录 `sourceProductId`、`sourceVersionId` 和 `sourceQuestionId`。
- 同一用户、同一资料题目在同一计划中不得重复生成错题。
- 用户确认的成绩、耗时和完成情况才进入能力统计。

### 7.8 订单与退款

- 用户可查看资料订单、金额、支付状态和购买时间。
- 已支付订单可以提交退款申请并填写原因。
- MVP 继续采用人工审核和人工确认外部退款结果。
- 退款完成后撤销对应资料 Grant，并保留订单、账本和退款审计记录。
- 是否满足退款条件由上线前确认的退款政策和实际使用记录共同决定，系统首版不自动承诺或自动拒绝退款。

## 9. 状态设计

### 9.1 商品状态

```text
draft → pending_review → published → unpublished
```

- `draft`：仅运营可见。
- `pending_review`：等待内容、版权和商品信息审核。
- `published`：可展示和购买。
- `unpublished`：停止销售；已购买访问按下架原因处理。

### 9.2 订单状态

```text
pending → paid → refunded
       ↘ closed
```

- `pending`：已创建，未确认支付。
- `paid`：服务端已确认支付并应存在授权。
- `closed`：超时、取消或运营关闭，不可继续支付。
- `refunded`：外部退款完成并已撤销授权。

### 9.3 资料授权状态

```text
active → expired
      ↘ revoked
```

- `active`：允许访问。
- `expired`：到达配置的有效期。
- `revoked`：退款、违规或人工纠错后撤销。

## 11. API 草案

> 以下均为待实现的新接口；不得把它们当作当前已存在的 API。

### 11.1 用户端读取

## 12. 权限与安全要求

1. 商品介绍和样章允许匿名读取，其余接口默认需要登录。
2. 付费章节同时校验用户、商品、版本、Grant 状态和有效期。
3. 管理后台内容接口必须校验管理员身份并记录审计日志。
4. 订单金额、商品状态和版本均由服务端读取，禁止信任前端价格。
5. 资源文件不放入公开 `/uploads` 静态目录。
6. 私有文件使用鉴权代理或短期签名 URL，URL 不应永久有效。
7. 内容缓存不得跨账号复用；退出登录时清理受保护内容缓存。
8. 支付回调需要校验签名、金额、订单状态和幂等键。
9. 补发、撤销、退款完成等高风险动作必须包含操作人、原因和外部凭据。
10. 日志不得记录完整支付凭据、用户 Token 或付费内容正文。

## 14. 核心指标

### 转化指标

- 资料首页到商品详情点击率
- 商品详情到样章打开率
- 样章到创建订单转化率
- 创建订单到支付成功率
- 支付成功到授权成功率及授权耗时

### 使用指标

- 购买后 24 小时打开率
- 7 日学习率和章节完成率
- 阅读到练习转化率
- 资料到 OA 计划创建率
- 错题复练率

### 风险指标

- 退款申请率和完成率
- 客服投诉率
- 无权限访问次数
- 支付成功但无 Grant 的订单数
- 已撤销 Grant 仍能读取内容的异常数

## 15. MVP 范围

### 15.1 MVP 必须包含

- 资料首页、搜索、分类和筛选
- 商品详情、目录和免费样章
- 购买确认、订单和 Mock 支付
- 支付回调后的资料授权
- 我的资料
- 图文和受保护 PDF 阅读
- 基础练习、收藏、笔记和进度
- 与 OA 计划、错题本联动
- 商品、版本、章节和上下架后台
- 订单、授权和退款查询
- 基础埋点和异常告警

### 15.2 MVP 不包含

- 用户上传并销售资料
- 优惠券、拼团、分销和多商户结算
- 批量 ZIP 或原始文件永久下载
- 离线资料包和复杂 DRM
- AI 自动生成或改写所谓公司真题
- 自动退款
- 动态定价和复杂推荐算法
- Web 端资料商城

## 16. 开发分期

### Phase 0｜文档与基线确认

#### 工作内容

- 复核现有支付、商业账本、退款、OA、API Client 和 migration 约束。
- 确认真实支付保持关闭，先使用 Mock 完成业务验证。
- 确认首批资料、版权状态、内容格式和负责人。

#### 验证

- 形成首批商品清单和内容模板。
- 明确现有可复用 API 与本项目新增 API。
- 真实支付开关和商业灰度保持 0%。

#### 禁止事项

- 不假设当前已经存在资料商品 API。
- 不修改现有 `planId 0～6` 的含义。
- 不把支付和普通页面开发混为一次高风险发布。

### Phase 1｜数据模型与运营后台

#### 工作内容

- 通过新 migration 增加商品、版本、章节、题目、订单项、Grant 和进度表。
- 建设商品、内容、审核、上下架和版本后台。
- 建立来源、版权和审核必填门禁。

#### 验证

- migration 可重复执行且 checksum 正常。
- 能创建、审核、发布、下架一个完整商品。
- 下架后新用户不可购买，已购用户策略符合配置。
- 未审核资料无法发布。

#### 禁止事项

- 不在业务路由中新增启动期 DDL。
- 不无痕覆盖已发布版本。
- 不允许后台直接把订单改为已支付。

### Phase 2｜商城、详情与我的资料

#### 工作内容

- 在资源中心增加测评资料入口。
- 实现列表、搜索、筛选、详情、样章和资料库。
- 新增独立 API 模块，统一处理登录、错误和缓存。

#### 验证

- 匿名用户可浏览商品和样章。
- 未购买用户无法读取付费章节。
- 已购买状态、最近进度和下架状态正确展示。
- 页面不直接调用 `wx.request`。

#### 禁止事项

- 不把商品列表硬编码在页面 JS 中。
- 不依赖本地 Storage 判断用户是否已购买。
- 不在会员页承载全部资料管理功能。

### Phase 3｜订单、支付与授权

#### 工作内容

- 扩展订单支持资料商品和价格快照。
- 复用现有支付回调、商业账本、退款和告警。
- 支付确认后幂等生成资料 Grant。

#### 验证

- 重复回调只产生一个 Grant。
- 金额不符、签名失败、用户不匹配均不授权。
- Mock 支付完整覆盖创建订单、确认、查询和退款撤销。
- 支付成功但 Grant 缺失时产生告警。

#### 禁止事项

- 不由前端直接发放权限。
- 不把待支付订单展示为已购买。
- 不绕过现有真实支付审批与灰度门禁。

### Phase 4｜阅读器与 OA 联动

#### 工作内容

- 实现受保护阅读、进度、收藏、笔记和基础练习。
- 将资料题目关联现有 OA 计划和错题本。
- 增加跨设备进度合并和账号切换保护。

#### 验证

- 权限撤销后旧链接和缓存无法继续读取。
- 跨设备读取位置和进度最终一致。
- 同一资料题目不会重复进入错题本。
- 未经用户确认的数据不进入能力统计。

#### 禁止事项

- 不创建另一套 OA 能力评分和错题体系。
- 不公开私有文件真实存储路径。
- 不把练习样本不足包装为确定能力结论。

### Phase 5｜真实支付灰度与上线验证

#### 工作内容

- 完成资质、商品、退款政策、客服和隐私文本审核。
- 完成生产备份、migration 演练和支付沙箱验证。
- 从 0% 开始，经人工审批后进入小流量灰度。

#### 验证

- 真实支付、重复回调、金额不符和退款撤销均有证据。
- 5xx、支付回调、Grant 缺失和私有资源异常有真实通知人。
- 5% 灰度观察 30～60 分钟，无关键异常后再决定是否扩大。
- 恢复到 0% 不影响免费资料和现有求职功能。

#### 禁止事项

- 不因 Mock 通过就直接开启生产收款。
- 不自动执行生产 migration、退款或放量。
- 不在没有版权和售后流程的情况下发布付费内容。

## 17. 验收清单

### 商品与内容

- [ ] 商品可按公司、岗位、招聘季和题型搜索筛选。
- [ ] 商品详情展示完整目录、样章、版本和更新说明。
- [ ] 未审核或已下架商品不能新购。
- [ ] 内容更新有版本和变更记录。
- [ ] 所有付费商品都有来源、版权和非官方声明。

### 订单与授权

- [ ] 成交金额由服务端计算并写入订单快照。
- [ ] 支付回调幂等，重复回调不重复授权。
- [ ] 已支付订单存在对应账本和 Grant。
- [ ] 退款完成会撤销对应 Grant。
- [ ] 用户不能读取其他用户的订单、授权和进度。

### 阅读与练习

- [ ] 匿名用户只能访问公开介绍和样章。
- [ ] 已购买用户可以跨设备继续学习。
- [ ] 退出登录或授权撤销后无法继续读取缓存内容。
- [ ] 资料练习可关联 OA 计划和错题本。
- [ ] 进度、收藏和笔记在冲突时不会被旧状态覆盖。

### 运营与发布

- [ ] 运营可完成商品、版本、章节和上下架管理。
- [ ] 高风险后台操作有操作者、原因和时间记录。
- [ ] 全量自动化测试、专项支付测试和 migration 演练通过。
- [ ] 真实支付、退款和生产 migration 已经过人工审批。
- [ ] 可一键恢复商业灰度为 0%，免费功能不受影响。

## 18. 待产品评审决策

1. 首批公司专项包和题型专项包的具体清单。
2. 单品、组合包和免费体验包的价格策略。
3. “购买大版本永久访问”是否作为统一政策。
4. PDF 是否允许单文件临时下载，还是仅允许小程序内预览。
5. 退款政策中对已阅读章节数、购买时间和内容问题的处理边界。
6. 首批内容由内部原创、外部授权还是合作方提供。
7. 生产环境是否在 MVP 阶段接入私有对象存储。
8. Pro 会员是否享受资料折扣；首版建议不做自动折扣，避免增加订单复杂度。
