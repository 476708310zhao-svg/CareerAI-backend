# 职引微信 AI 开发模式评测准备

参考微信官方《[评测指南](https://developers.weixin.qq.com/miniprogram/dev/ai/evaluation-guide.html)》（2026-11-16 读取）。这两份 JSON 是供官方评测插件上传的**初稿**，不是平台已通过的评测结果。

## 现有能力

`miniprogram/app.json` 声明了 3 个只读 Skill：

| Skill | 原子接口 | 范围 |
| --- | --- | --- |
| `job-search` | `searchJobs`、`getJobDetail` | 真实岗位搜索、从搜索结果查看详情 |
| `campus-calendar` | `searchCampusOpportunities`、`getUpcomingDeadlines` | 校招搜索、即将截止机会 |
| `interview-prep` | `searchInterviewExperiences`、`getInterviewExperienceDetail` | 真实面经搜索、从搜索结果查看详情 |

不包含自动投递、提醒写入、虚构岗位或面经。评测文件不含用户个人数据、生产库记录或未经证实的业务对象 ID。

## 文件

- `intent-set-20-selftest-20261116.json`：20 条，先用于开发者自测；含岗位、校招、面经及边界场景。
- `intent-set-50-20261116.json`：50 条，42 条正例与 8 条标记的负例，用于微信团队评测的候选文件。覆盖 3 个 Skill 的 6 个原子接口，并包含时间及未注册场景意图。

官方插件会对格式、接口覆盖、复杂度、多样性和适用的场景标签作平台检测。本地只验证了 JSON 格式、数量、标签和去重；**不能把本地通过当作平台检测通过**。若平台判定本小程序需要完整的时间或位置标签覆盖，现有 Skill 只有相对时间窗口和明确地区筛选，需依据检测报告调整用例或补足实际业务能力，不能给不支持的意图硬贴标签。

## 操作顺序

1. 安装并打开最新微信开发者工具 Nightly 版，载入唯一项目 `D:\ChatGPT-Projects\求职小程序\jobapp-server\miniprogram`；编译模式切到「小程序 AI 编译」，调试基础库选 3.16.2 或以上。
2. 先确认当前 AppID 的「开发模式」权限可用，逐个执行六个原子接口并检查卡片、真实结果、无结果及来源不可用时的展示。
3. 点击开发者工具中的「评测插件」，选择「自测」，选包含这 3 个 Skill 的已上传版本，上传 20 条文件；生成用例、生成轨迹，核对异常及未注册用例，查看报告。
4. 按报告修复 Skill 后，上传包含最终 Skill 的**最新体验版**。评测插件选择「提交给微信团队评测」，上传 50 条文件；该模式会评测全部 Skill，不能屏蔽某个接口，文件检测必须全部通过。
5. 在插件内核对生成的用例、轨迹和报告；需要人工核验的场景按官方流程补录。根据报告继续修正并重新评测。体验版、普通小程序代码审核和 AI 开发模式评测是不同状态，分别核对。

当前电脑此前打开的是微信开发者工具 Stable 版；本轮没有安装 Nightly、登录微信平台、上传体验版或启动评测。用户需在评测插件中以自己的平台账号完成相关操作。
