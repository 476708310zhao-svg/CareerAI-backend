# 测评资料统一说明

所有测评商品共用使用、领取、更新、售后四段说明，在后台“测评资料 → 统一说明”一次配置，不需在飞书每条商品记录重复填写。

## 配置与接口

- `GET /admin/api/v4/assessment-instructions` 返回四段文案、`version`、`configured`。
- `PUT` 同路径提交四段文案及读取时的 `expectedVersion`，需后台 `memberships` 或 `*` 权限，响应 `no-store`。拒绝空段、HTML、脚本链接、超过 20000 字的段落及已知私有网盘地址。
- 用户确认的正式文案保存在 `assessment-shared-instructions-20261019.json`，不是默认值、种子或自动发布脚本；应在明确目标的正式迁移完成后显式配置一次。使用说明保留了用户提供的温馨提示。
- 商品详情读取当前统一说明，返回 `instructionsVersion` 和 `purchaseEnabled`；创建新订单必须提交 `expectedInstructionsVersion`，不匹配返回 409，前端刷新并要求重新确认。
- 修改统一说明会关闭资料待付款订单；旧付款请求的迟到收款沿用人工核对流程，不直接交付。会员订单不受影响。

## 数据兼容与上线顺序

0014 正式迁移只创建空单例（版本 0）并关闭资料待付款订单，不复制旧单品文案、不改已付快照、收款账本、来源说明或领取天数。旧单品四列保留供历史追溯，商品保存不再更新这些列。

先备份、迁移到 0014，再显式配置四段文案，最后核对真实商品并上架。未配置完整时可保存草稿或下架，禁止新上架及任何新订单；首页推荐隐藏，详情购买关闭。0014 未应用时共享接口、商品公开列表/详情和保存返回受控 503，首页安全隐藏；旧单领取不依赖共享表。已购幂等先返回原订单。

统一设置审计复用 `assessment_product_audit`，以 `product_id=0` 表示商品集合设置，`shared_instructions_updated:vN` 记录版本，`actor_id` 标识管理员。表中 0 是无外键的显式集合哨兵值，不是实际商品。已付订单继续使用原快照说明，不因后续统一文案改变而被改写。

本改动不启用 Mock 生产付款、不改变 900 分定价或现有真实支付审批门禁，不自动操作飞书、不含私有交付地址。
