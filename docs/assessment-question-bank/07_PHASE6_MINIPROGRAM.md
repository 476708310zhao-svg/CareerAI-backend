# 阶段 6：小程序免费在线刷题（2026-10-21）

## 本批交付与产品边界

资源中心新增独立的“在线刷题”入口，进入原生题集目录和练习会话页。目录只展示服务端 `/api/v4/question-practice/sets` 返回的已审核、显式开放且当前授权有效的免费题集；同一账号的会话、历史、错题和收藏沿用阶段 4 的服务端记录，因此与网页共用进度。资源中心原有 OA 本地模拟入口、9 元测评资料入口和购买流程保留原语义。

用户已决定会员题集暂不开通，9 元资料独立。本批没有会员购买入口、会员权益判断或支付改动；已购买 9 元测评资料不会自动产生在线刷题权限。后端免费发布闸门 `qb_free_web_publications` 是唯一题集目录来源，未发布时显示明确空状态。任何原创或授权题仍需按阶段 4 审核并由有权限的管理员显式公开。

## 页面与请求

- `package-content/pages/practice-home`：免费题集、继续练习、完成历史、错题、收藏；服务端分页。点击题集用稳定 `clientKey` 创建或恢复 active 会话。错题和收藏使用本人当前视图的游标栈，提供上一页、当前页和下一页；每次切页先清旧题面、向服务端重新取该页，避免撤权后旧页内容因新页成功或失败而继续显示。切账号或撤权清游标；失权项只显示不可查看提示，不用本地题库补题。
- `package-content/pages/practice-session`：读取本人会话及顺序快照后再取当前题。单选、多选和判断只在本地保存本题当前选择；正式提交、跳过 `null` 和判分由服务端完成。标准答案和解析只从提交成功或本人已提交题目的 `result` 响应显示。进度写明“第 n / N 题”。已提交题可收藏、取消收藏；可结束会话并从目录查看历史。
- `utils/api-question-bank.js`：所有题面、会话、错题和收藏 GET 关闭客户端缓存；写请求沿用身份绑定和服务端幂等键。页面隐藏、退出、切换账号或收到撤权/登录失效时清除已显示的题干、选项、答案和解析，旧请求的迟到响应不得覆盖新账号页面。
- 正式提交网络结果不确定时，页面保留该题原 `requestId` 和原答案，禁止改选或跳过；重试提交复用它们。同一小程序进程内 Page 销毁再重建，待确认提交只留在按账号世代绑定的内存中。重进先查本人 `sessionDetail` 和 `result`；已提交就显示服务端结果并同步本地进度，未提交再复用原键。进程重启后内存丢失，仍先查服务端结果；若 GET 与另一个提交竞态，第二次 POST 的 409 再以 `result` 对账。账号变化、登录失效或撤权会擦除待提交内存。
