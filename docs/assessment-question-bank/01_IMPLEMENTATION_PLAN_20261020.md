## 阶段 1：最小私有 PDF 资产导入

### 1A：先做可测试的后端底座

- 新增迁移，拟从 `0016_private_pdf_assets.sql` 起（**落地前重新检查迁移最大版本号**）：批次、资产、来源、处理状态、文件哈希与审计。迁移只追加表/索引，不修改测评商品、订单、会员或既有上传表。
- 新增私有存储适配接口：开发/测试用 `DATA_DIR` 下不受 Express 静态服务的私有目录，生产适配器待对象存储核实后实现；禁止使用 `UPLOAD_DIR` 或公开 `/uploads`。
- 管理员新建批次、准备上传、完成确认、查状态/失败重试。服务端检查真实文件类型、尺寸和哈希，不信任浏览器的“上传成功”回报；重复文件保留多条来源记录。
- 接口前缀建议 `/admin/api/v4/question-assets/*`，最终以现有路由树评审确定。加专用后台权限映射；测试未知权限、普通运营越权和匿名访问。

**复制位置**：迁移机制 `db/migrate.js:32-64,111-178` 与 0012/0015 迁移写法；用户和管理员路由包装 `routes/assessment.js:10-29`、`routes/admin-assessment.js:8-25`；权限映射 `utils/adminPermissions.js:43-91`；响应 `utils/response.js`。先阅读这些源文件再写，不假设存在 `ResourceAsset` 或 COS SDK。

**验收**：隔离测试 DB 上迁移可重复校验、schema checksum 正确；同哈希不同来源不丢链；越权 401/403；故意损坏/伪扩展 PDF 被隔离；私有原件不能从 `/uploads` 或任何匿名路由读出；失败任务可定位、重试幂等。运行新增专项、`npm run check:db-migrations`、`npm test`。

**不得照搬**：`routes/upload.js` 的简历公开 URL、将试卷原件存在 `UPLOAD_DIR`、把 multipart ETag 当作全文件 SHA-256、在 HTTP 请求里长时间解析大 PDF。

### 1B：后台入口与生产存储适配

- 管理后台增加独立“PDF 素材/批次”页，显示文件状态、来源、错误和授权待审，不混入在售测评商品表。安全文本渲染、分页与请求竞态沿用 `admin/js/assessment-products.js:24-100,399-424`；在 `admin/js/common.js:277-305` 注册入口。
- 私有生产对象存储适配器只在核实实际配置和供应商文档后实现并做隔离联调；签发权限须限定对象与操作。没有私有存储或扫描能力时保持生产上传入口关闭。

**验收**：浏览器断网和重试状态与服务器一致；新批次不影响现有网盘资料商品；真实配置不用写入 Git；本阶段不开放学生阅读。

## 阶段 2：处理权、展示权与发布闸门

- 为资产、题目来源及媒体建立操作级授权：内部存储、机器处理、第三方处理、题干/图片展示、答案解析展示、商业访问、改编、期限/地域。未知项默认拒绝。采购记录只作来源证据，不能自动勾选公开权限。
- 内容审核与权利审核分为独立操作、独立权限和审计记录。`adminAuth` 对未映射路径只验证 admin 身份（见 `middleware/adminAuth.js:14-21`），所以新路由必须显式映射并对两种审核动作作路由级检查，不能仅挂中间件。
- 抽出服务端统一权利检查，供解析创建、题集发布、取题、取图和撤权复用。审批修改、授权到期或投诉撤权应立刻停止后续取题；短期媒体链接须单独验证失效窗口。

**复制位置**：`utils/adminPermissions.js:1-19,43-91` 的权限枚举/映射；`routes/admin-assessment.js:8-25` 的认证和 no-store；`tests/assessmentAdmin.test.js:95-172` 的后台状态/竞态测试。按 `docs/API_RESPONSE_CONVENTION.md` 返回错误。

**验收**：仅购买凭证、仅内部处理、允许题干但不允许图片、允许免费但不允许商业、到期、撤权各有测试；任何未获许可题都不能经公共 API 获取。运行权限与发布专项、迁移专项和 `npm test`。

**不得照搬**：把“在售商品”“会员有效”“管理员账号存在”当成题目授权；把默认值设为允许；允许运营自己单击批量批准绕过权利审查。

## 阶段 3：人工录题、不可变版本和题集

- 为单选、多选、判断建立受验证的题目内容 DTO；增加题目逻辑 ID、不可变修订、来源证据、媒体、审核记录、题集及题集顺序。纯原创题保留作者和归属证据，可不依附 PDF。
- 后台支持人工录题、编辑草稿、内容审核、权利审核、题集编排；一旦修订发布，改题必须产生新修订并重新审核。题集引用确定的修订 ID。
- 发布服务逐题检查题干、选项、答案、素材、审核和权利，不让后台通过直接改状态字段绕过。此阶段可先建内部题集，不暴露用户端入口。

**复制位置**：后台表单/分页 `admin/questions.html:100-139,184-215` 可借视觉和交互外壳；持久化及发布规则须新建；迁移结构参照 `db/migrations/0012_assessment_commerce.sql`，不是复制其商品含义。

**验收**：已发布版本不能被 UPDATE 覆盖；审核后再改答案会重置审批；图像无权展示时整题不发布；题集内版本顺序稳定。新增独立题库 API/服务测试并跑 `npm test`。

**不得照搬**：旧 `interview_questions` 的新增即发布、硬删除和公共答案出参；小程序 `oa-practice-bank.js` 中客户端持有标准答案的模式。

## 阶段 4：免费网页答题闭环

- 用户端 API：合法题集目录、开始会话、按顺序取题、正式提交、结束会话、错题、收藏、历史。创建会话时冻结题目修订与顺序；服务端判分；同题不同答案的第二次正式提交拒绝，同一请求 ID 重试返回首次结果。
- `GET` 取题只用白名单序列化题干/选项/获准图片，不能包含正确选项、解析、来源 PDF key。提交成功后才返回当前题可展示的答案和解析。每次取题/图/提交复查发布、授权、本人会话身份；免费题集不依赖新支付功能。
- 网站在 `public/web` 新建练习视图与资源入口，沿用 `public/web/app.js:9-21,131,162` 的身份绑定请求和视图模式；首发只展示已审免费题集。

**验收**：单选、多选全对、判断、未答、并发提交、重复请求、跨用户访问、撤权中途、版本更新后历史稳定；直接抓 API 不能提前拿答案。网页弱网刷新可继续做题。专项、全量 `npm test`、Web 页面手工验收均记录结果。

**不得照搬**：客户端判分、全量题库 JSON 下发、把 `oa-bank.js:200-210` 的用户自报成绩计入正式答题历史。

## 阶段 5：数字 PDF 辅助识题

- 建异步解析任务与 checkpoint，数字 PDF 文本优先；保留页号、坐标/块、解析器版本和来源哈希。分题先按题号/章节规则切块，再识别题后和文末答案，关联键至少含试卷版本、章节和题号。
- 结果只生成待审草稿；缺答案、冲突、重复题号、双栏错序和复杂图形提示人工修订。审题工作台显示原页与题目字段，编辑留审计。没有授权或预算时任务停在明确状态，不执行外部处理。
- 用开发包 `05_合成测试用例.json` 做确定性单测；再对实际获授权样本按 PDF 类型测切分、答案匹配、漏题、修订工时。扫描页先标为待 OCR/人工，不虚构识别结果。

**复制位置**：可参考 `routes/upload.js:116-127` 现有 PDF 文本抽取调用方式，但需要单独验证页坐标/读序工具；任务重试模式参考 `routes/v4/agents.js:15-43`，长任务隔离与并发参考 `scripts/dispatch_reminders.js`。外部解析/OCR SDK 在官方文档和环境确认前不列为“已可用 API”。

**验收**：无可靠答案证据的题绝不发布；同文件/解析器版本重试不重复草稿；文末同题号不同章节不串答案；Worker 中断能恢复；按样本类别报告真实质量和成本。专项、迁移、全量回归通过。

**不得照搬**：把 `pdf-parse` 一段合并文本当精准页面布局；让模型猜“官方正确答案”；把 PDF 内文本当 Worker 指令执行。

## 阶段 6：小程序与会员题集

- 新建 `miniprogram/utils/api-question-bank.js` 和原生答题页，接入同一服务端练习 API。资源中心可增加“在线刷题”入口，保留现有 OA 与测评资料卡片语义；需要产品决定旧 OA 本地练习的并存/迁移文案。
- 页面保护账号切换、请求世代、弱网重复提交和退出续答，沿用 `miniprogram/utils/api-assessment-resources.js:9-25,89-106` 与 `assessment-list.js:22-67` 的客户端模式。判分数据从服务端响应取得，不在分包内嵌标准答案。
- 会员题集仅在产品确认权益编码后，通过 `services/v4Membership.js:18-38` 实时读取并在每次取题校验；退款/会员到期测试必须覆盖。现有 9 元资料购买不自动开通刷题。

**验收**：同账户网页/小程序的进度和错题一致；切账号不串数据；会员到期、撤权后下一题被拦截；Android/iOS 真机及当前主要小程序页面回归通过。运行专项、`npm run check:miniprogram`、`npm run check:release`。

**不得照搬**：`oa-practice-bank.js:13-35` 的客户端答案、`oa-bank.js:46-92` 的客户端判分；把演示/预览数据兜底到正式题库。

## 阶段 7：发布前验证与运维

1. 对照 `00_PHASE0_DISCOVERY_20261020.md` 的可用 API 逐一核验最终代码；检索公开 DTO 是否含答案/解析/私有对象 key、是否仍有未知管理路径只验 admin、是否把试卷放进 `/uploads`、是否从前端判分。
