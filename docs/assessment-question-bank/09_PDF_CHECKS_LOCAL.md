# 私有 PDF 安全校验（本地开发）

上传成功只代表原件已进入私有隔离区。管理员在“PDF 素材导入”的来源记录中点击“运行安全校验”，后端会记录一次检查：重新核对原件 SHA-256，调用本机 ClamAV 或 Windows Defender 扫描，在限时子进程中逐页检查 PDF 结构，然后再次核对 SHA-256。结果和时间保存在 `question_pdf_asset_checks`，资产仍需独立的来源授权及内容审核。

## 当前无扫描器时

结构检查仍会运行，并可显示页数及“校验通过”。扫描结果保持“待扫描”，检查记录为“受阻”；辅助识题、发布和刷题不会因此放行。不要直接修改数据库状态来绕过扫描。

## 扫描器

优先使用本机 ClamAV：让 `clamscan` 可从服务进程的 PATH 调用，或在本地配置 `QUESTION_PDF_CLAMSCAN_PATH` 为可执行文件的完整路径。只有扫描摘要确认本次扫描了 1 个文件、病毒库非空、感染数为 0 且进程成功退出，资产扫描状态才会成为 `clean`。

Windows 上找不到 ClamAV 时，尝试 Windows Defender。要求 Defender 服务、防病毒和实时防护均开启，病毒库年龄不超过 7 天；使用自定义文件扫描且关闭自动处置。仅在命令明确报告“扫描完成、未发现威胁”后标为 `clean`。病毒库过期、更新失败、结果含糊、超时、文件被更改或扫描器失效，资产均不放行。更新病毒库后重启本地服务，再对同一来源运行安全校验。

状态变成“PDF 校验通过 / 扫描通过”后，再到“来源授权与审核”登记并核准机器处理、题干和答案展示等对应权益及内容审核；随后到“辅助识题”创建任务、逐页处理并人工复核识题草稿，最后在“题集管理”创建题目、审核题集并按已有发布流程开放免费刷题。当前辅助识题草稿与正式题库仍是两个独立环节，不能把未经人工复核的草稿直接发布。

接口（需要已登录且仍拥有 `questionAssets` 权限）：

- `GET /admin/api/v4/question-assets/sources/:sourceId/check` 查询资产状态与最近一次检查。
- `POST /admin/api/v4/question-assets/sources/:sourceId/check` 重新检查私有原件；同一资产检查进行中拒绝重复启动。

生产环境的私有存储与扫描部署尚未接入；本功能沿用 `QUESTION_PDF_LOCAL_IMPORT_ENABLED=1` 的本地开发限制。
