# UGC 发布前审核说明

更新时间：2026-07-29

## 审核范围

- 用户面经
- 面经评论
- 评论回复
- 机构评价

## 状态流转

用户提交内容后，服务端统一写入 `pending`。公开列表、详情、点赞及评分统计仅使用 `approved` 内容。

管理员可在管理后台执行：

- `pending → approved`：内容开始公开展示。
- `pending → rejected`：内容不公开，可填写驳回原因。
- `approved → rejected`：内容立即停止公开，评论数或机构评分同步重算。

每次状态变更都会写入 `content_moderation_logs`，记录内容类型、内容 ID、前后状态、审核备注、审核人和时间。

## 管理入口

- 面经管理：`/admin/experiences.html`
- 评论与回复管理：`/admin/comments.html`
- 机构评价管理：`/admin/agencies.html`

管理页面默认展示待审核内容，并支持查看全部、已通过和已驳回内容。

## 微信审核说明建议

可在提审备注中填写：

> 小程序涉及用户发布的面经、评论、回复及机构评价。所有用户生成内容提交后默认进入待审核状态，审核通过前不会在公开列表或详情页展示。运营人员通过管理后台进行人工审核，可通过、驳回或删除内容；审核状态变更保留日志。平台同时设置登录鉴权、写入频率限制、用户删除和后台处置机制。
