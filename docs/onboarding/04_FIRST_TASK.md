# 首个入项任务：ONBOARD-01

## 可直接发给新成员的任务书

**目标：**在自己的机器上从指定基线独立克隆项目，完成本地环境复现和代码检查；找出交接文档中的实际阻塞点。

**基线 / PR 目标：**`codex/release-20261116`。任务分支示例：`feat/onboarding-check`。在 GitHub 创建 PR 时核对 base，勿保留默认的 `main`。

**允许修改：**`docs/onboarding/02_LOCAL_SETUP.md`，以及确有事实错误时的 `README.md`。如需改其他文件，先在任务中说明并由维护者确认范围。不要修改业务代码、迁移、生产配置或真实数据。

**步骤与验收：**

1. 按 [本地启动文档](02_LOCAL_SETUP.md) 克隆、安装依赖、配置本地 `.env`。记录系统、Node/npm 版本，但不提交 `.env` 或凭据。
2. 执行 `npm run check:miniprogram`、`npm run check:release` 和 `npm run check:acceptance -- --no-report`。记录每项退出码、通过/跳过/失败及有代表性的非阻断提醒。
3. 若文档有可复现错误，在允许范围内修正并发 PR；PR 附原步骤、修正后的步骤和验证结果。若文档准确且无需改动，在任务中提交复现报告即可，不创建空 PR。
4. 提交前确认 `git status --short --branch` 没有 `.env`、数据库、上传文件、真实用户资料或临时产物。

**维护者提供：**仓库访问、审阅人、PR 目标分支。此任务不需要生产权限、微信平台账号或第三方 API Key。
