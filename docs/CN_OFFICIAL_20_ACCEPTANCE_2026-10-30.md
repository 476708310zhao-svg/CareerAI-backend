# 20 家企业官网试点：数据修复与本地验收（2026-10-30）

## 修复

- Ashby 招聘板的 `isListed=false` 职位不再出现在搜索结果，也不能通过官方职位 ID 查询详情。依据：[Ashby 公开岗位 API 文档](https://developers.ashbyhq.com/docs/public-job-posting-api)。当前两家 Ashby 试点板的原始数据没有此类职位；修复防止以后误展示。
- Greenhouse 中 `internal_job_id=null` 的 prospect post 不作为真实招聘岗位展示。依据：[Greenhouse Job Board API 文档](https://docs.greenhouse.io/job-board)。
- 多地点职位选择明确位于中国内地的地点显示，避免把国外主地点和 `CN` 国家代码拼在一起。
- 10 家公开招聘板冷启动请求错峰 120 毫秒；单次 HTTP 502/503/504 最多重试一次。403 和限流不立即重试，故障仍在 `boardStatus` 中如实呈现。

## 真实来源抽查

2026-10-30 在本地环境执行只读 GET 检查，未提交申请或写入企业系统。岗位数量为当次查询快照，会变化。

| 检查项 | 结果 |
| --- | --- |
| 10 家国内企业官网入口 | 10/10 返回 HTTP 200；阿里巴巴、拼多多入口跳转到各自的校招路径 |
| 10 家自动同步招聘板 | 首轮并发读取 5/10 收到临时 HTTP 502；失败来源依次复测均返回 200；修复后的生产节奏查询 10/10 返回结果或真实空结果 |
| “实习”中国内地岗位 | 19 条，9 家有匹配、1 家无匹配；无重复职位 ID |
| 职位字段 | 19/19 有岗位描述、内地地点、官网职位详情及申请链接；5 条有来源明确的发布时间，其他 14 条留空；无推测薪资 |
| 职位详情页 | 19/19 返回 HTTP 200 |
| 申请链接 | 首次检查 18/19 返回 200，1 条临时 502；该条随后复测返回 200 |

HTTP 200 证明检查时入口可以访问，不证明企业最终会接受申请。来源 502 属于短时可用性问题，不应显示成“没有岗位”。
