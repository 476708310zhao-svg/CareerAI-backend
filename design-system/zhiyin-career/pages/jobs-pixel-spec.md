# 找岗位页像素规范

## 基准与覆盖规则

- 固定验收视口：`390 × 844`。
- 视觉基准：`.agents/skills/zhiyin-miniprogram-pixel-replica/assets/jobs-approved.png`。
- 用户后续明确要求移除多个 Tab 页顶部的标题和副标题，因此实现不得恢复原型中的“找岗位 / 为你精选…”页头；其余搜索、快捷筛选、校招日历、推荐列表与卡片仍以原型为准。
- 页面业务状态、筛选、收藏、加入进度和登录流程保持原有数据合同。

## 页面结构

1. 顶部直接进入搜索与筛选，不设置装饰性大标题。
2. 搜索下方显示最多四个岗位方向快捷入口。
3. 校招日历作为单行入口，使用浅色图标底和右侧箭头。
4. “推荐岗位”标题下直接进入纵向岗位卡片列表。
5. 自定义 Tab Bar 悬浮在页面底部，列表保留安全区尾部空间。

## 视觉参数

- 页面水平边距：`16rpx`。
- 页面背景：浅蓝白渐变；不使用黑色大色块。
- 卡片背景：接近白色，`28rpx` 圆角，细描边和低强度蓝灰阴影。
- 正文字体栈：系统字体、苹方、微软雅黑；只使用 `400 / 500 / 600 / 700` 的稳定字重。
- 主标题：`34rpx / 700`；岗位标题：`30rpx / 600`；辅助文字与标签：`24–25rpx / 400–600`。
- 搜索、筛选、日历、箭头、收藏和关闭均使用统一 SVG 图标，不使用 Unicode 符号或 CSS 临摹图标。
- 交互控件保留足够点击区域；长岗位名与公司名必须单行省略，不挤压收藏操作。

## 全球产品约束

- 找岗位默认范围为“全球”，不能默认把美国或加拿大当成产品边界。
- 地区筛选可选择全球及常用国家/地区，具体覆盖以真实岗位数据源为准。
- 工作资格使用跨地区语言；`美国 H-1B` 等术语必须显式标注适用地区，不能写成全球通用规则。
- 任何无法确认的签证、工作许可或公民身份要求都应提示核实，不得由 UI 推断为已满足。

## 验收

- 使用稳定岗位 fixture 编译，避免接口波动改变截图内容。
- 先核对首屏几何、字体层级、图标和卡片密度，再运行像素差异比较。
- 主要几何偏差超过 `2px`、旧样式残留或首屏结构不一致时不得提交。
